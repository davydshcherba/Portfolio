01 About

About

I grew up watching my father work at his computer, and that curiosity turned into code when I was eleven. My first money came from selling stickers at school — the instinct to ship something people actually want has stuck around since.

Today I work mostly on the backend: async Python with FastAPI, PostgreSQL through SQLAlchemy, everything packaged in Docker so it runs the same way anywhere. I care about the unglamorous parts — clear schemas, honest error codes, CI that fails loudly before anyone else sees a bug.

I also handle the frontend when a project needs one, using React, Next.js and TypeScript. Away from the keyboard I follow motorsport — Formula 1 above all, where the engineering matters as much as the driving.

Vision

2026

A student task dashboard: assignments with a title, description, due date, status and attached files, laid out on a three-column kanban board. Files open in the page — PDFs in the browser's viewer, images as they are, text in monospace — so nothing has to be downloaded just to be read. The interface switches between Ukrainian and English, and API error messages follow the choice through Accept-Language.

Built both sides. Backend: async FastAPI split by layer — routers do HTTP only, logic and file handling live apart — with SQLAlchemy 2, Alembic migrations that run on start, per-file and per-task upload limits, and a batch upload that saves the good files and reports each bad one with a reason. Frontend: Next.js 15 and React 19 in TypeScript, drag & drop between columns, size checks before sending and real upload progress over XHR. The whole stack — Postgres, API, frontend, Adminer — comes up with one docker compose up.

Tally

2026

A fast, self-hosted URL shortener with built-in click analytics. Shortens any link to a random 7-character code or a custom alias, tracks total and unique clicks per link, and supports optional expiry — expired links stop redirecting and answer 410 Gone.

Built the whole service: async FastAPI app, PostgreSQL schema and migrations, API-key-protected admin endpoints, and a Docker Compose setup that brings the database, migrations and API up with a single command. CI runs on every push.

To-Do CLI

2026

An interactive command-line task manager. Add, list, complete and remove tasks from a prompt; everything is stored as JSON under ~/.todo-cli, so the list follows you between projects and survives reinstalls.

Built it with zero third-party dependencies — the standard library only. Commands live in their own modules behind a small dispatcher, and a custom @logger decorator wraps every action to append it to a per-day JSON log. Keyword-only arguments and defensive loading keep a hand-edited tasks file from crashing the app.
